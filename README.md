# CoreSense Understanding System

This repository contains the CoreSense Understanding System, including a bringup package as well as a package (coresense_understanding_interfaces), useful in coresensifying existing ROS services or getting Modelets out of <a href="https://github.com/kas-lab/triplestar_kb">Triplestar KB</a>, our chosen RDF database wrapper.
